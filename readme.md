#  Le Grimoire du Développeur

**Le Grimoire du Développeur** est un site web qui rassemble une sélection de ressources et de cours gratuits pour apprendre et approfondir ses connaissances en développement informatique.

##  Le concept

Plutôt qu'un catalogue de liens classique, le site prend la forme d'un **grimoire magique interactif**, plongé dans l'univers d'une bibliothèque fantastique.

Chaque page du grimoire présente une ressource avec une illustration, une courte description et un ou plusieurs lien vers les sites proposant le cours.

Les ressources sont organisées en plusieurs catégories :
- **Front-end** : HTML, CSS, JavaScript, React, Angular…
- **Back-end** : Java, PHP, Symfony, Spring Boot…
- **Bases de données** : SQL, Merise, UML…
- **Algorithmique** : concepts, structures de données et algorithmes.
- **Outils** : Git, Docker et autres outils de développement.

##  Objectif

L'objectif est de **centraliser des ressources pédagogiques utiles et accessibles gratuitement**, tout en proposant une manière originale et immersive de les découvrir.

Le site ne propose pas directement de cours : il sert de passerelle vers des plateformes, documentations et tutoriels externes.

##  Technologies

Le site est développé avec **HTML, CSS et JavaScript vanilla**, sans framework, avec des animations CSS 3D pour donner vie au grimoire.

Les ressources sont stockées dans un fichier JSON afin de faciliter leur ajout et leur mise à jour.
